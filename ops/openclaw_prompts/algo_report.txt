Run `cd /opt/swarm-trader && poetry run python -m src.algo.monitor_report` and use its JSON to send one concise Algo paper-account Telegram report. This is read-only: never place, cancel, or modify orders. Put the report time in America/New_York in the title. Aim for about 1,200 characters and stay below 2,000.

Lead with service.active, market_state, last_scan_status, strategy_scan_age_seconds, entries_paused and entry_pause_reasons. Flag a stopped service, stale scan, actual scan_errors, unowned_positions, or data_errors clearly; do not present missing data as healthy. Do not label data_status.quotes=session_limited, or legacy quotes=degraded with successful requests and only stale/missing held-quote diagnostics, as a service/feed failure: state neutrally that the extended-session feed has not updated some quotes inside the freshness window, list affected held symbols from the diagnostics, and note that new entries remain paused until fresh quotes return. A stale/missing quote means quote-based software exits cannot be evaluated for that symbol at that moment; separately report broker protection problems only when the healthcheck confirms them. If warnings is present, distinguish warnings from problems. State the deterministic market regime and its reason, active strategies, regime_advisory status when present, and notable strategy_lifecycle transitions.

Show the selected universe count and all tickers, additions/removals, and largest price changes since the previous report. If comparison_available is false, say this is the initial comparison. Show each held ticker with strategy owner, quantity, entry/current price, unrealized P&L and price change since the prior report, using compact rows. Highlight startup_reconciliation or ownership uncertainty when present.

Include daily and weekly P&L, entry_orders_today versus entry_order_cap, open_positions versus max_open_positions, and circuit-breaker states. For orders_since_previous_report include symbol, side, quantity, strategy, submission status and broker status. A submitted or legacy `executed` journal row is only a submission. Say filled or partially filled only when Alpaca broker_status confirms it, and include filled quantity/average price only if present.

When the session is OVERNIGHT, identify BOATS historical bars as at least 15 minutes delayed and distinguish them from the overnight quote feed used for current prices/exits. Mention actual quote request failures distinctly from session-limited quote freshness. If there are no changes or orders, say so. If the command fails or the JSON is invalid, report that failure explicitly with the available error and do not invent account or trading status.
